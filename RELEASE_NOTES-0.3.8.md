# EMET 0.3.8

EMET is an MCP server for document control (ISO 9001 7.5.3 / ISO 13485 4.2.5): persistent shared memory for AI agents, bot teams, and chats. Version 0.3.8. EMET holds no certification and claims no conformity. The stored document shapes are not frozen. Pin a version if you depend on them. Stored rows are not rewritten. No new setting is required. This revision is not published from this file. See [CHANGELOG.md](CHANGELOG.md).

You can sign a bot, a member, or a guest in with its sub-key and source tag. EMET Console is a separate app that talks to `/console/api`. An unregistered source is refused on and after 2026-12-15. A skipped reload after a chat summary warns when continuity currency is on. `read_doc` reports whether the stored body matches its digest. The owner can approve one shorter revision of a named document. The prior revision stays.
